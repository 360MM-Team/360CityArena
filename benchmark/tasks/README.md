# Task CSVs

Each CSV file defines one 360CityArena task family:

- `localization.csv`
- `landmark_search_language.csv`
- `landmark_search_image.csv`
- `counting.csv`
- `map_navigation.csv`
- `language_guided_navigation.csv`
- `relational_spatial_reasoning.csv`

The public catalog currently contains 25 tasks per family, 175 tasks total.
