# Task Taxonomy

360CityArena currently exposes seven task families:

- Localization: infer the initial grid cell from exploration and a reference map.
- Landmark Search with Language: navigate to a named landmark.
- Landmark Search with Image: navigate to a landmark shown in a reference image.
- Counting: count specified objects within a constrained range.
- Map Navigation: navigate from a start marker to a goal marker using a reference map.
- Language Guided Navigation: follow natural-language directions to a destination.
- Relational Spatial Reasoning: identify a nearby landmark satisfying a spatial relation.

The public release contains 25 tasks per family, 175 tasks total.
